## WorkSphere – Staff Management App

WorkSphere is a web application that allows visual and interactive management of employees on a workplace floor plan in real time.

### Features
- Add, assign, move, and remove staff in rooms
- Role-based zone restrictions (ex: Réception → only receptionists)
- Unassigned staff sidebar
- Detailed profile modal
- Responsive design (desktop → mobile)

###  Technologies
HTML • Tailwind CSS • JavaScript • VS Code • Jira/GitHub Projects
